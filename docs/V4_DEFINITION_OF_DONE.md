# Aureon V4 Gold — Definition of Done

V4 is complete as a software architecture only when all of these contracts are present and passing. Historical/live profitability remains an evidence question, not a software-completion claim.

1. **Journey model:** pre-cross pressure, confirmed EMA20/50 cross, EMA200 context, expansion, pullback, re-entry observation, continuation and exhaustion/reversal are represented without future leakage.
2. **Movement labels:** remaining +3/+5/+10/+20/+30/+40, MFE and MAE are resolved after the anchor.
3. **Pullback intelligence:** depth, ATR/retracement context, EMA/structure retests, volume contraction and continuation re-expansion are retained.
4. **Context:** Asia/London/New York/overlap plus M15/H1 frozen context and state transitions are available.
5. **Specialists:** continuation, remaining-move, pullback, exhaustion, MAE and regime routing exist with minimum-sample safeguards.
6. **Similarity/explainability:** similar resolved journeys, positive/negative evidence, uncertainty, similarity confidence and OOD handling are available.
7. **Learning:** resolved successes and failures remain in learning memory; weekly and drift-triggered retraining create versioned Candidates.
8. **No automatic promotion:** retraining never installs a Champion directly.
9. **Governance:** Candidate -> Challenger -> Shadow -> Champion is sequential, requires base-rate improvement and strictly unseen weekly evidence.
10. **Drift:** Champion degradation is monitored and triggers retraining/review rather than replacement auto-promotion.
11. **Placement research:** pre-cross/cross/re-entry comparisons, missed movement and paired opportunity cost exist.
12. **Management research:** fixed +3, fixed +5, partial+runner and pullback-continuation summaries remain research-only and are not realized P&L claims.
13. **Discord:** one journey thread presents remaining movement, pullback/re-entry observations and similar-history evidence without computing indicators or creating orders.
14. **Live/replay parity:** identical frozen V4 features, journey context and model artifact produce identical hashes and predictions; mismatches fail loudly.
15. **Execution boundary:** V4 remains intelligence. Human confirmation and the existing execution boundary remain unchanged.

Passing this definition means the V4 Gold implementation is structurally complete. It does not by itself certify a trading edge; that requires real unseen and live evidence.
