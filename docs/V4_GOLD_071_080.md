# Aureon V4 Gold — TODO 071-080

This block adds reliability controls and the V4 weekly learning loop. It is intentionally unable to promote itself.

- **071 Prediction uncertainty:** combines probability ambiguity with lack of historical similarity.
- **072 Historical-similarity confidence:** requires both enough neighbours and close neighbours.
- **073 Stronger OOD handling:** insufficient similar history, low similarity, high uncertainty, or an unseen local regime marks the prediction OOD. OOD confidence is forced to zero.
- **074 Continuous outcomes:** V4 resolved examples can be appended continuously to outcome memory.
- **075 Weekly training:** a seven-day cadence and minimum-new-evidence trigger are supported.
- **076 Versioning:** each Candidate gets a timestamp plus deterministic training-set fingerprint.
- **077 Failed outcomes:** misses are retained as first-class training evidence.
- **078 Emergency drift retraining:** drift can trigger training before the weekly cadence.
- **079 No auto-promotion:** every weekly model is created as Candidate with auto_promote=false.
- **080 Weekly report:** reports observed target rates, mean model probabilities, similarity coverage, retained failures and the explicit governance requirement.

Existing V3 operational safeguards informed these contracts, but V4 uses V4 journey examples and does not mutate the V3 production lifecycle.
