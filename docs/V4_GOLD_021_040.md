# Aureon V4 Gold — TODO 021-040

This slice adds live-shaped pullback, re-entry and phase-volume intelligence on top
of the V4 movement foundation.

## Pullback intelligence

- Detect pullback only after a confirmed EMA journey has expanded by a minimum move.
- Measure depth in price units, ATR units and as a fraction of the preceding expansion.
- Track pullback duration in bars.
- Classify SHALLOW / NORMAL / DEEP retracements.
- Detect EMA20, EMA50, EMA200 and optional structure-level retests.
- Mark structure invalid when retracement exceeds the configured failure fraction or
  breaches the supplied structure level.

## Re-entry research

- Create a research-only re-entry observation after pullback stabilization.
- Require directional EMA20/50 alignment and price/EMA200 alignment when EMA200 is
  available.
- Require structure to remain intact.
- Measure future MFE, MAE and +3/+5/+10 continuation from the re-entry price.
- Retain failed re-entry observations, including adverse movement before +3.
- Provide a cross-vs-re-entry placement comparison helper.

No execution request or order is generated by this feature.

## Volume phases

Volume remains MT5 tick-volume context, not centralized exchange volume.

V4 now keeps these phases separate:

1. pre-cross 3-bar / 5-bar mean volume,
2. exact cross-candle tick volume and relative-volume ratio,
3. mean tick volume during the post-cross expansion.

The candle that starts a pullback is deliberately excluded from expansion volume.

## Runtime

The live observer now advances the V4 pullback tracker from the same closed candle
and indicator read used by the rest of Aureon. EMA200 is exposed through
`AnalysisEngine.indicator_read` so re-entry alignment does not depend on a stale
detection snapshot.

Journey close first finalizes open V4 re-entry outcomes, then runs the existing V3
canonical-example reconciliation.
