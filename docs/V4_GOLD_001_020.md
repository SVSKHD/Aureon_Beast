# Aureon V4 Gold — TODO 001-020

This slice establishes movement intelligence on top of the existing deterministic
V3 EMA journey. It deliberately does not add pullback/re-entry logic yet; those
begin at TODO 021.

## Implemented contracts

- One V4 movement journey view: pre-cross -> confirmed cross -> expansion -> close.
- Stable ordered event sequence for pre-cross, EMA20/50 and price/EMA200 anchors.
- Pre-cross movement, duration in bars and seconds, and failed-pressure labels.
- Cross ordering and movement already consumed when each cross becomes observable.
- Remaining movement labels are measured from each confirmed cross, never from a
  hypothetical earlier fill.
- Separate research model for P(cross within 1/3/6/12 bars).
- Separate remaining-move model for +3/+5/+10/+20/+30/+40, expected remaining
  MFE and expected remaining MAE.
- Probability ladders are constrained: cross-within probabilities are
  non-decreasing with time, while remaining-target probabilities are
  non-increasing with larger targets.

## Safety / chronology

All V4 features are frozen from information available at the observable anchor.
Labels come only from later resolved journey outcomes. Failed pre-cross pressure is
kept as training data rather than silently dropped.

The production Champion/Challenger/Shadow lifecycle is intentionally not changed by
this slice. V4 model governance and weekly lifecycle work are later V4 tasks.
