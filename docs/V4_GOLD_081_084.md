# Aureon V4 Gold — TODO 081-084

V4 now has a strict governance boundary.

**081 Lifecycle:** Candidate -> Challenger -> Shadow -> Champion. Every transition checks the current state; a model cannot skip directly to Shadow or Champion.

**082 Base-rate improvement:** Candidate validation and Shadow evidence must improve Brier score over the observed base-rate predictor by the configured minimum. A model that merely looks accurate because the positive class is common is not enough.

**083 Weekly unseen validation:** Challenger evidence must come from market dates strictly later than the Candidate training cutoff. Overlap raises an error. The unseen-week metrics are frozen before Shadow admission.

**084 Champion drift:** recent resolved V4 outcomes are compared with absolute Brier limits, Shadow-era Brier and current base-rate edge. Drift requests emergency retraining and review. It never promotes a replacement automatically.

This layer remains research/intelligence governance. It does not place trades.
